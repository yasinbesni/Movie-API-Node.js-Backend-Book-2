# Başlangıç — Birinci kitabın final Movie API projesi

Bu klasör, **Node.js ile Backend: Sıfırdan Gerçek Bir API Geliştirme Rehberi** kitabının 70. bölümündeki Movie API kaynak projesinin kopyasıdır. Başlangıçta `User` modeli, hesap oluşturma doğrulaması veya kimlik doğrulama sistemi **yoktur**. Bunları ikinci kitabın ilgili bölümlerinde oluşturacağız.

Çalışırken buradaki `code/movie-api` klasörünü ayrı bir çalışma klasörüne kopyalayın; `package.json` bu klasörün içindedir. Projede bir kez `npm install` çalıştırın. `.env.example` dosyasını temel alan özel `.env` dosyanızı oluşturun. `MONGODB_URL` için canlı değil, yerel veya ayrı bir deneme veritabanı kullanın.

Bu başlangıç sürümü, birinci kitabın orijinal kaynak koduyla birebir aynı tutulmuştur. Bölüm klasörlerindeki `code/` dosyaları yeni projenin tamamını tekrar etmez; yalnızca ilgili bölümdeki **tam, bağımsız dosya örneklerini** gösterir. Kısmi ekleme ve değiştirme adımları `kod_ornekleri.md` içinde kalır ve kitaptaki sırayla mevcut çalışma dosyasına uygulanır.
