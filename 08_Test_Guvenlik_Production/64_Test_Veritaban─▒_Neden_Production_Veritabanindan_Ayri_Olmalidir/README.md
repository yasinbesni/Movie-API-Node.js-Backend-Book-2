# 64. Bölüm — Test Veritabanı Neden Production Veritabanından Ayrı Olmalıdır?

**Kitaptaki kaynak:** `08_Test_Guvenlik_Production/64_Test_Veritaban─▒_Neden_Production_Veritabanindan_Ayri_Olmalidir.md`

**Başlangıç:** Birinci kitabın 70. bölüm Movie API projesi (`00_Baslangic_Movie_API/code/movie-api/`). 01. bölümden itibaren her değişiklik **aynı çalışma projesine** uygulanır. Her bölüm yeni bir proje oluşturmaz.

**Bu bölümde tek başına tam dosya olarak yayımlanmış bir değişiklik bulunmuyor.** Öğretim amaçlı örnekler ve mevcut dosyaya eklenecek parçalar `kod_ornekleri.md` içindedir.

**Örnek dosyalar:** `kod_ornekleri.md` içinde ilgili kitabın tüm kod ve HTTP örnekleri bölüm sırasına göre vardır. *Eksik import'lar, tek başına çalışmayan alan tanımları veya kısmi parçalardan çalışan dosya üretilmemiştir.*

**Çalışma şekli:** Önce kitap bölümünü okuyup kodu kendi çalışma kopyanızda uygulayın; sonra bu klasördeki örneklerle karşılaştırın. Tamamlanmayan sonraki bölümün API yolunu bu aşamada çalışır kabul etmeyin. Eski film kataloğu korunur; kullanıcı kayıtları ve güvenlik özellikleri ancak ilgili bölümde eklenir.
