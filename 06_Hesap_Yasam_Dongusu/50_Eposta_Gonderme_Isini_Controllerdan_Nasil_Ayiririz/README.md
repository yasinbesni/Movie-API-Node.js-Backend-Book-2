Kitaptaki 50. bölümü okuyup değişiklikleri kendi Movie API çalışma kopyanıza uygulayın. Kod ve HTTP örneklerini `kod_ornekleri.md` dosyasından karşılaştırabilirsiniz.

- `code/src/services/email.js`

Bu klasör, **aynı projede yaptığımız 50. adımı** gösterir. Uygulamanın bütünü veya baştan kurulacak farklı bir proje değildir. Başlangıç kopyasının nasıl hazırlanacağı kod deposunun ana README dosyasında anlatılıyor.

## Ortam ayarları

`code/example.env` bu bölümün çalışma kopyası için örnektir. Dosyayı uygulamanızdaki `package.json` dosyasının yanına `.env` adıyla kopyalayın. Bu klasörde yalnız değişen dosyalar varsa onları mevcut projenize uygulayın; parçaları tek başına başlatmayın.
